# Памятка на следующий рабочий цикл

Заполни для одного пользовательского сценария. Пока обязательная проверка не пройдена, не ставь PASS.

## Перед реализацией

- [ ] Владелец: пользователь делает ___ через обычный вход ___ и получает ___; после повторного открытия видно ___; при ___ должно произойти ___.
- [ ] Проектировщик: контракт ___; ответственный механизм ___; вне задачи ___; для состояний, повторов и сбоев — переходы и короткая матрица проверок.
- [ ] Диспетчер: базовая версия ___; один исполнитель и разрешенная область записи ___; зависимости и порядок ___; где нужно независимое ревью: ___
- [ ] Бюджет: время ___; шаги исследования ___; раунды ___; кто решает при остановке: ___
      Стартовое правило: два неполных исправления одного класса → пересмотр постановки.

## Кандидат и ревью

- [ ] Исполнитель передал точную версию ___, среду ___, шаги/команду ___ и полный релевантный вывод.
- [ ] Через реальный вход получен наблюдаемый результат; сохранение подтверждено повторным чтением; выполнена негативная проверка: ___
- [ ] Подмены и непроверенное отмечены явно. Если назначено независимое ревью, проверяющий воспроизвел нужное на том же снимке. Граница: обязательный путь, связанные зависимости и отказы; не общий аудит.
- [ ] Для блокера записаны требование или реальный риск, проверяемое доказательство и последствие. Новый критический риск отмечен отдельно, даже если его не искали.
- [ ] Диспетчер назначил каждой находке решение: блокер / нужно доказательство / нужно архитектурное решение / долг / неверно. Спор о контракте или риске передан владельцу с проектировщиком.
- [ ] На новой версии перепроверены исправления, изменившиеся поверхности и регрессии. Закрытое переоткрыто только при новом основании.

## Допуск или остановка

- [ ] Статус: PASS / BLOCKED / НЕ ПРОВЕРЕНО. Слияние — только для проверенного кандидата без блокеров, с подтвержденными обязательными условиями.
- [ ] При исчерпании бюджета: остановлены автоматические правки, сохранены версии и доказательства, записаны непроверенное и следующий ответственный. Независимые задачи не ждут без причины.
- [ ] До выпуска еще нужно: ___
- [ ] Записаны результат сценария и регрессий, повторные классы находок, время до первого доказанного результата и разбивка задержек: провайдер / рассуждения / инструменты и тесты / лишние повторы.
