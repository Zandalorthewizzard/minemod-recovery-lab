# Minemod recovery lab

Восстановление мода **Minemod: Shellback** (Fabric, Minecraft 26.3, Java 25): проверяем уже
существующую базу, доводим её до наблюдаемого результата и измеряем путь до него.
Это **лаборатория, а не релиз**: готового продукта в репозитории нет, `main` не тронут.

## Текущий статус

- База импортирована из upstream `f69785bbe1…` без изменения байтов; свежий прогон R1 —
  на коммите `20eeb6d8…`, изолированный worktree, JDK 25.0.5+8, Gradle 9.7.0,
  Fabric API 0.165.2+26.3.
- `clean build` — успех (231 с); серверные GameTests — 26 кейсов, 0 падений (5.024 с);
  `runClientGameTest` — успех (250 с): клиент поднялся, мир загрузился, `/summon` принят.
  JAR `minemod-0.1.0.jar`, SHA-256 `dd62c12e…46fecc` ([`metrics/r1-runtime.json`](metrics/r1-runtime.json)).
- «26/26» здесь **воспроизведено нами**, а не унаследовано: 25 модовых сценариев плюс
  ванильный `minecraft:always_pass`.
- Продуктово **не доставлено**: внешний вид моба и улучшенного щита (рендерер работает на
  ванильной модели, иконки предметов — ванильные текстуры), подсказка рецепта (нет
  advancement — рецепт не появляется в книге), ощущение боя живым игроком (окно парирования
  проверено только на стенде).
- Ветка `intake/verified-export-0.1.0`, открыт draft PR #1; тегов и релизов нет. Лицензия не менялась:
  `All-Rights-Reserved`, `authors: []`. Публичный репозиторий не означает открытую лицензию.

Матрица «что проверено / только в тесте / не подключено / требует проверки» —
[docs/RECOVERY-STATUS.md](docs/RECOVERY-STATUS.md).

## Правило документов

Один документ — одна задача. Копий текста нет: совпадающее утверждение живёт в одном месте,
остальные документы ссылаются на него. Новый документ появляется в таблице
[docs/PROJECT-MAP.md](docs/PROJECT-MAP.md) в том же коммите, что и сам файл.

## Чего здесь нет

Распакованных Minecraft/Fabric/JDK и ванильных текстур, готовых JAR мода, исторических логов,
worktree, переписки и Git bundle — они остаются вне публичного дерева. Здесь только
source-only baseline, его происхождение и новые рабочие документы.
